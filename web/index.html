    Each key shows what it holds and when it was last changed. Edit renames it and rewrites its stores and permissions in place — the key itself is never shown again and never changes, so whoever holds it keeps using the same key. Editing is disabled for a revoked key, and revoking cannot be undone.

      The key is kept in memory only: reloading this page forgets it. There is no cookie, no stored copy and no key in the address bar.
